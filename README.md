# Deepseek联网工具

> [!IMPORTANT]
> **只需在 MaiBot 的「模型设置 → 模型提供商（供应商）」中配置好官方 DeepSeek，插件无需单独配置 API Key。**
>
> 插件会自动复用该提供商的密钥，MaiBot 的主模型可以继续使用其他提供商。只有一个官方 DeepSeek 提供商时，无需额外设置；有多个时，可在 MaiBot 模型设置中把要使用的那个命名为 DeepSeek。插件界面不再提供模型提供商页面。

使用 DeepSeek 官方 Search 和 Fetch API，为 MaiBot 提供网页搜索和 Markdown 正文抓取。搜索结果与网页正文交给 MaiBot 当前主模型归纳。

原名 DeepSeek Anthropic Provider。版本 0.3.0；保留插件 ID、仓库地址和安装目录，方便现有用户升级：

- 插件 ID：LowValueTarget.deepseek-anthropic-provider
- 仓库：<https://github.com/LowValueTarget777/deepseek-anthropic-provider>
- 入口：plugin.py / create_plugin()
- SDK：maibot-plugin-sdk >=2.5.2,<3.0.0
- 网络依赖：httpx >=0.28.1,<1.0.0

## 功能

| Tool | 用途 |
| --- | --- |
| search_and_summarize | 调用 POST /v1/tools/search，返回相关摘要、链接、日期、排序分数和可选正文，供主模型总结 |
| fetch_page | 调用 POST /v1/tools/fetch，获取指定公开网页的 Markdown 正文，支持长文本分段返回 |

搜索词支持站点、排除词、精确短语、语言和日期语法。抓取不再借助模型搜索猜测网页内容。本插件不在本地抓取或解析网页 HTML。

## 安装与升级

在 MaiBot 的 plugins/deepseek-anthropic-provider 目录运行：

~~~bash
uv sync
~~~

密钥只在 MaiBot 的“模型设置 → 模型提供商（供应商）”中配置：添加或检查官方 DeepSeek 提供商，接口地址使用 https://api.deepseek.com（也识别原来的 /v1 或 /anthropic 地址）。提供商可以任意命名，无需把 DeepSeek 设为 MaiBot 的主模型，也无需在插件设置或插件配置文件中再次填写密钥。

通常插件会自动读取当前 MaiBot 的 config/model_config.toml。如果只存在一个官方 DeepSeek 供应商，插件无需额外配置即可使用。有多个时，优先使用名称为 DeepSeek 的官方供应商（不区分大小写）；仍无法确定时会提示在 MaiBot 模型设置中调整名称。

旧版的 provider.provider_name 与 provider.model_config_path 仍兼容，但仅作为本地 config.toml 中的高级选项，不显示在插件配置界面。特殊部署才需要手动指定配置文件路径，正常安装不必填写。

MaiBot SDK 当前的 config.get() 只公开 Bot 配置，未提供读取模型供应商密钥的能力。因此本版使用标准 TOML 解析器只读读取本机模型配置，不导入 src.*、不修改主程序或模型配置、不把密钥复制到插件配置。隔离环境必须允许插件读取该文件；不能读取时会明确提示。

升级后重载插件。0.2.x 的启用状态、超时、并发限制、重复请求合并与日志开关会迁移；旧的 auth、model、thinking 和 Anthropic server search 设置会移除。旧密钥不会继续写进插件配置，也不会作为备用鉴权。通用推理 Tool deepseek_proxy 已移除。

为兼容 Runner“先重建配置、后调用插件迁移”的顺序，插件工厂会先只读提取本插件旧 config.toml 中的超时、并发、请求合并和请求日志四项非密钥设置，作为首次升级的默认值；已显式填写的新字段优先。首次注入配置后即清除这些迁移默认值，不缓存旧配置或历史密钥，也不修改模型配置。

仓库只提交 config.example.toml，不跟踪运行时 config.toml。历史安装第一次跨越“删除受跟踪配置”的提交时，若 git pull 因本地 config.toml 修改而中止，请先备份该配置，临时还原受跟踪文件后更新，再恢复备份；之后此文件由忽略规则保护。不要提交真实配置或强制清空工作区。

## 配置

WebUI 保留顶部标签页：

| 分组 | 设置 |
| --- | --- |
| 基础设置 | 插件开关 |
| 网页搜索 | 默认请求 50 条、原始问题与本地化 IP、站点/语言/短语/日期条件、最新消息、质量筛选、排序、去重、返回字段与文本预算 |
| 网页抓取 | 抓取开关、每段正文长度，默认 30000 字符 |
| 性能与超时 | 默认总时限 120 秒、并发 4、每接口每秒 4 次、同会话在途请求合并 |
| 调试与日志 | 搜索来源、请求摘要和测试命令开关 |

总时限包含读取配置、排队、限速和网络等待。两个接口分别限速，执行与等待的请求总数上限 64；不自动重试。客户端复用连接池，密钥每次从模型配置读取。卸载会取消请求并关闭连接。同一会话完全相同的在途请求可合并，不缓存完成的结果。

插件为两个 Tool 和调试命令声明 660 秒的组件 RPC 时限，覆盖最高 600 秒的请求配置与回包余量，避免被宿主默认 60 秒提前截断。实际联网请求仍按用户设置的总时限结束，默认仍是 120 秒。

### 搜索条件与返回选项

在“网页搜索”中可直接设置以下选项，不必让主模型每次手写搜索语法：

| 设置 | 用法与默认行为 |
| --- | --- |
| 默认结果条数 | 默认请求 50 条；Tool 的 count 可覆盖。已有配置中明确保存的条数不会被强改 |
| 传递原始问题 | 默认开启；仅转发 Tool 提供的 ori_question，不设置固定问题，也不读取聊天记录 |
| 默认本地化 IP | 默认留空；填 IP，不填地区名称。Tool 明确传入时优先，传空字符串可取消默认 IP |
| 默认限定站点 / 排除站点 | 列表中每项填一个域名，不含协议或路径；限定多个站点自动用 OR 组合 |
| 排除词或短语 / 精确匹配短语 | 列表中每项一个词或短语，自动处理空格与引号；排除条件始终叠加 |
| 默认结果语言 | 每项填 zh、en 等语言代码，自动组合为 lang: |
| 发布日期范围 | 可填 YYYY 或 YYYY-MM-DD；查询显式日期优先，其次固定范围，最后才是最新消息范围 |
| 最低排序分数 / 最低权威性 | 默认 0 / -1，均表示不筛选；开启后未知指标也会被过滤，可能减少结果 |
| 结果排序 / 重复网页去重 | 默认按综合相关性排序并去重；可选发布时间或权威性。仅重排本次已召回的结果 |
| 摘要类型 / 返回字段 | 默认长摘要优先，缺失时回退短摘要；日期、分数、权威性、站点名称默认返回，图标默认不返回 |
| 搜索文本总长度上限 | 默认 60000 字符，平均分给各条结果，优先标题与摘要；单字段仍受 4000 字符上限约束 |

query 是本次搜索的动态关键词，不适合设成固定配置。query 中明确的 site: 和 lang: 优先于对应默认值；全局排除词、排除站点和精确短语仍生效。追加所有条件后须满足接口 128 字限制，超长会明确报错，不会偷偷去掉筛选。各条件默认留空，建议只设置长期需要的少量条件。

排序和摘要类型使用真正的中文选项，字段说明写入宿主支持的提示字段。旧配置中的 relevance/date/authority 与 summary/snippet/both 仍可读取，会自动归一化为对应中文值；工具返回的 result_info.sort_by 保持原英文标识，方便下游兼容。

50 是向接口请求的上限，不保证一定返回 50 个不同网页。无匹配、去重或质量筛选后可能更少；Tool 的 result_info 会说明收到/返回条数、过滤和去重数量。质量筛选不自动回退或追加请求，全部被筛掉时会提示调低要求。较高分数不等于事实正确。

标题和 URL 始终保留。去重仅归并规范化后相同的 URL（忽略默认端口与域名大小写），保留路径、查询参数、片段和 HTTP/HTTPS 的差别；例如 /#/article/1 与 /#/article/2 不会合并，普通章节锚点也保留。文本预算不包含 URL 与元数据；截断会返回对应的 *_truncated 标记及提示，仍保留所有入选链接，可按需调用 Fetch，不会自动抓取 50 个网页。正文仍默认关闭，避免放大网络响应与主模型输入。

### 搜索最新消息

在“网页搜索”标签页开启“搜索最新消息”，并设置“最近多少天”（默认 7 天，可设为 1～365 天）。开关默认关闭。

开启后，插件按北京时间计算日期，并自动给查询追加官方支持的 after:YYYY-MM-DD 条件。例如北京时间 2026-10-17 搜索最近 7 天，会追加 after:2026-10-10。搜索词已明确指定 after: 或 before: 时，保留其时间范围；配置了固定发布日期范围时也不叠加近期限制，方便查询历史消息。

这是按发布日期进行的日期过滤，不是精确的小时窗口，也不保证即时收录或按最新到最旧排序；仍需核对结果的发布日期和事件日期。若追加条件后超出接口 128 字限制，会提示缩短关键词，不会静默截断或去掉时间过滤。网页抓取不受此开关影响。

## 使用

正常对话中让主模型选择工具，例如：

- “查一下 DeepSeek 最新发布的官方说明，优先看官网。”
- “只查最近一个月的英文技术文档。”
- “读取这个网页的正文并总结重点。”

搜索词示例：

~~~text
DeepSeek site:deepseek.com lang:zh,en after:2026-10-01
~~~

search_and_summarize 接受 query（1～128 个 Unicode 字符）、count（1～50）、need_content、ori_question（原始问题，1～128 字）和 localization（本地化 IP，可省略）。不要把国家或地区名称直接当作 localization。

fetch_page 接受 url（最长 8192 字符的 HTTP/HTTPS 地址，不含用户名或密码）和 start_char（正文起点，默认 0）。返回内容包含标题、Markdown、总长度、是否截断与下一段起点。继续读取长页面会再次调用 Fetch API，可能再次计费；插件会明确提示。

工具返回的网页和链接是供主模型核验的资料，不应作为指令执行。插件不直接发送工具正文到聊天，也不自动在回复末尾追加来源列表；主模型仍可根据用户要求引用来源。

## 调试命令

~~~text
/deepseek_web_status
/deepseek_web_search_test DeepSeek 官方文档
~~~

状态命令只检查本机供应商配置，不发出付费请求，也不验证远端鉴权。搜索测试执行一次真实搜索，有有效结果时才报告成功。旧命令 /deepseek_anthropic_ping 和 /deepseek_anthropic_search_test 作为别名保留。

Search 和 Fetch 的计费、账号级限速与网页访问限制以[官方文档](https://api-docs.deepseek.com/zh-cn/guides/search/)为准。配置了官方模型供应商并不代表账号一定具有新接口权限，首次使用请实际测试。

## 常见问题

- 未找到供应商：确认模型供应商的接口地址属于官方 api.deepseek.com；第三方转发供应商的密钥不会发送到官方接口。
- 多个 DeepSeek 供应商：在 MaiBot 模型设置中把要使用的官方供应商命名为 DeepSeek；旧版已指定的供应商名称继续有效。
- 无法读取模型配置：确认文件路径与进程读取权限，特殊部署可在本地配置中指定 provider.model_config_path。
- 401：在 MaiBot 模型供应商设置中检查密钥；402：检查账号余额。
- Fetch 返回 403/404：目标被安全策略拒绝、不可访问或没有可提取正文。不会改用模型常识补写。
- 429：账号或目标域名限流；本插件的本地限速不能协调其他客户端的调用。
- 结果为空：搜索没有命中，调整关键词、日期或站点限制后再试。
- 正文太长：读取返回的下一段起点；不要把第一段当作完整页面。
- Bot 未使用工具：由 MaiBot 主模型决定是否调用，确认主模型支持工具调用。主程序工具返回长度限制仍可能影响长正文，请结合当前 MaiBot 设置排查。

请求摘要日志仅记录接口、状态、请求标识和耗时，不记录密钥、查询或正文。搜索来源日志包含 URL，公开日志前请检查其中是否含私人参数。

uv run pytest -q -m "not integration"

~~~
