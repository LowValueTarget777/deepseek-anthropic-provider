# Search / Fetch 验收

本版直接调用 DeepSeek Search 与 Fetch API，不由插件中的额外模型执行检索或总结。离线测试验证协议与资源管理，真实质量需要人工验收。

## 固定样本

| 场景 | 操作 | 验收 |
| --- | --- | --- |
| 官方资料 | 搜索 DeepSeek site:deepseek.com | 结果属于指定站点，摘要与原文相符 |
| 默认条件 | 配置多站点、语言、排除词、短语 | 请求为官方搜索语法，显式条件优先，合并后不超过 128 字 |
| 界面兼容 | 查看排序/摘要选项与设置说明，载入旧英文配置 | choices 真正为中文，hint 包含说明，旧值映射后仍可保存使用 |
| URL 去重 | 同域名大小写/默认端口重复、不同 /#/ 与 #! 路由和章节锚点 | 合并重复 URL，保留不同路由、片段与查询参数 |
| 召回与质量 | 默认请求 50 条，对比关闭筛选和设定质量阈值 | 区分原始命中、质量过滤与重复网页数量，全部过滤时有说明 |
| 排序与字段 | 对同一批候选切换日期/权威性排序，关闭指标返回 | 未知指标排后，隐藏字段不改变筛选，排序仅影响已召回候选 |
| 文本预算 | 50 条含正文结果，降低文本预算 | 链接仍保留，文本不超预算，截断标记与后续 Fetch 提示清晰 |
| 时效资料 | 使用 after: 与 before: 固定时间范围 | 区分事件日期与页面发布日期 |
| 最新消息开关 | 开启最新消息，分别设为 1 天和 7 天 | 请求包含按北京时间计算的 after: 条件，Tool 返回实际过滤范围 |
| 历史范围优先 | 开启最新消息后搜索带 before: 的历史查询 | 保留明确的原始日期条件，不叠加近期限制 |
| 语言 | 使用 lang:zh,en | 检查结果语言，不仅看界面摘要 |
| 排除网站 | 使用 -site: | 排除结果符合预期 |
| 无结果 | 使用不存在的精确短语 | 空 results 与说明，不虚构回答 |
| 正文 | need_content=true | 返回真实正文或明确为空，截断带标记 |
| 指定文章 | Fetch 带文章 ID 的公开 URL | 标题和 Markdown 与该页面一致 |
| 长页面 | 读取第一段并用 next_start_char 继续 | 段落起点正确、截断明显、提示再次计费 |
| 不可访问 | 抓取无效、登录或被限制 URL | 清晰失败，不以模型常识补写 |
| 配置轮换 | 修改模型供应商密钥后发起新调用 | 使用最新供应商 key，插件配置不含 key |

记录服务返回的排序分数、权威性与日期，但不要把分数直接等同于事实正确。最终答案还取决于 MaiBot 主模型如何使用结果。

## 性能

在相同供应商与网络条件下记录总耗时、错误率、条数与正文长度，比较只要摘要和包含正文的响应。按固定样本重复测试，统计中位数与 P95。测试账号的其他客户端会影响限流结果。

比较 50 条候选下长摘要优先、长短摘要同时返回、启用正文的 JSON 大小与主模型输入长度。默认摘要优先、去重与文本预算旨在减少重复输入，不代表已测得真实联网延迟下降；正文开关影响上游响应，返回字段/预算仅在本地处理，不减少上游传输量。不要将截断文本当作完整网页。

另外检查连接池复用、同会话重复请求合并、跨会话不合并、两个接口独立限速、超时与取消、卸载后连接关闭。请求摘要日志只记录接口、状态、请求标识和耗时，不包含查询、正文或密钥。

宿主源码可用时验证真实 Runner 的重建顺序：旧配置并发 2、超时 90、关闭请求合并、开启请求日志，升级后仍保留；显式新字段可覆盖旧值，后续配置更新不受迁移默认值影响。检查组件声明在宿主超时解析后为 660 秒，而实际请求仍遵守用户配置的总时限。契约测试不替代实际等候超过 60 秒的运行验收。

## 执行

离线：uv run pytest -q -m "not integration"。真实测试需显式设置 RUN_DEEPSEEK_INTEGRATION=1，并让插件可读取正确的模型配置后运行 uv run pytest -q -m integration。只有有意启用时才执行真实请求，可能计费。

本文件是验收方案，不表示已经完成真实 API 验证。API 的价格和限速以[官方文档](https://api-docs.deepseek.com/zh-cn/guides/search/)为准。
